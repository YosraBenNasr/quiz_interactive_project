# Quiz Interactif - Projet FIA3

Ce projet est une page web interactive de quiz réalisée pour le sujet *Page de Quiz interactif* (FIA3 2025/2026).

## Structure du projet
- `index.html` — page principale
- `style.css` — styles (responsive, animations)
- `script.js` — logique du quiz, feedback en temps réel
- `rapport.md` — compte-rendu du projet (format markdown)

## Fonctionnalités
- Feedback visuel immédiat (bonne / mauvaise réponse)
- Score final et détails des réponses
- Téléchargement d'un rapport texte des résultats
- Accessible au clavier (Enter / Space)
- Responsive (mobile, tablette, desktop)

## Exécution
Ouvrir `index.html` dans un navigateur moderne (Chrome, Firefox, Edge).
